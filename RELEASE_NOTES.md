# HAD — İlk Kararlı Yayın

HAD, Xiaomi / Redmi / POCO cihazlarda HyperOS ve Android paketlerini root gerektirmeden ADB üzerinden yönetmeye yardımcı olan Windows uygulamasıdır.

### Sistem
- Windows 10 x64
- Windows 11 x64

### Başlıca özellikler
- Paketleri risk seviyelerine göre sınıflandırma
- User 0 için kaldırma
- Devre dışı bırakma / etkinleştirme
- Paket geri yükleme
- APK / split APK yedekleme
- Debloat DB güncelleme
- Platform Tools kurulumu
- Android USB sürücüsü kurulumu/güncellemesi
- Cihaz, ROM, RAM, depolama ve batarya bilgileri
- Normal / Fastboot yeniden başlatma
- Kritik sistem paketlerine karşı koruma

### İndirme
Aşağıdaki **HAD.exe** dosyasını indirin.

### Önemli
Uygulama her açılışta sorumluluk reddi metnini gösterir. İşlem yapmadan önce önemli verilerinizi yedekleyin.

### Dosya doğrulama
Yayınladığınız son EXE'nin SHA-256 değerini release yayımlanmadan hemen önce yeniden hesaplayıp buraya ekleyin.
